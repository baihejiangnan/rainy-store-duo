# 雨夜便利店 · 街角微缩模型

一个完全由代码生成的日式雨夜便利店街角微缩 3D 场景，无 Blender、无外部模型/贴图。

## 打开

双击 `雨夜便利店.html`（或同目录的 `dist/index.html`），用 Chrome / Edge 打开即可。
整个页面自包含（约 0.9 MB），可离线运行。

- 拖拽：旋转视角
- 滚轮 / 双指：缩放
- 无任何 UI；未操作时缓慢自动环绕，拖拽时暂停
- 无人物

## 场景内容

- 12×12 正方形微缩底座、黄铜铭牌与切面边缘
- 便利店：双面玻璃橱窗、自动滑门、招牌/竖招牌、雨棚、灯箱、店内货架/饮料柜/收银台/咖啡机/关东煮/杂志架/海报等
- 街角：自动贩卖机、自行车、伞架、垃圾桶、电线杆与电线、路灯、信号灯、路牌、护栏、停车位、排水沟、斑马线、小巷入口、空调外机、公告栏、猫
- 雨夜：持续降雨、檐滴、积水涟漪、玻璃雨水、自动门、招牌轻微闪烁、交通信号灯循环、湿地反射
- 三渲二：MeshToonMaterial 分档 + 反向外壳轮廓线 + 自定义 Bloom / 移轴微缩感 / 色彩分级

## 源码

- `src/main.js`：入口、相机/交互、灯光合并、静态合批优化
- `src/core/`：布局、调色板、程序化贴图、材质、几何、湿地反射、后处理
- `src/scene/`：environment / ground / storeExterior / interior / props / surroundings / atmosphere

重新构建：`node build.mjs --minify`
